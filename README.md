# Property Management Platform

A property management application built with React, TypeScript, Cloudflare Workers, and Cloudflare D1.

## Current Features

- Dashboard shell
- Properties page
- Property and unit data from D1
- Unit details page
- Worker (backend) API
- Cloudflare D1 database

## Tech Stack

- React
- TypeScript
- Cloudflare Workers
- Cloudflare D1
- Vite
- GitHub
